## Release process reminder (prereleases)

The org `release.sh` integer-bumps major.minor.patch and regenerates CHANGELOG via git-cliff, so it cannot
cut a `-beta.N` prerelease against the hand-curated CHANGELOG. Prereleases use the manual path: hand-edit
CHANGELOG + VERSION, annotated `v*` tag, push (shared `release.yml` auto-creates the GitHub Release; flag
`--prerelease` manually afterward — the workflow doesn't detect the suffix). **Always wait for the full CI
matrix to go green on `main` before tagging.**
