## The SQLite locker bug that ate 3 commits (read before touching locking)

File: `src/Stores/Locking/SqliteChainLocker.php`.

**Root cause:** the importer writes the marker row *inside* the `append()` callback — i.e.
inside `SqliteChainLocker`'s `BEGIN IMMEDIATE` transaction. The locker had been gating
`BEGIN` / `COMMIT` / `ROLLBACK` on `PDO::inTransaction()`. On some PHP/PDO + SQLite builds
`inTransaction()` returns a **stale** value after a failed statement (or after Testbench
migration work), so:

- it would skip `BEGIN` thinking it was already in a transaction → callback writes escaped
  the rollback we owe them; and
- on the error path `inTransaction()` returned `false` after a failed insert even though the
  raw `BEGIN IMMEDIATE` transaction was still open → `rollBack()` was skipped → a marker could
  survive a failed envelope append (a stranded marker / duplicate-suppression hazard).

**Fix (final shape in `8861828`):**

- Stop trusting `PDO::inTransaction()`. Always issue raw `BEGIN IMMEDIATE` and let SQLite be
  the source of truth. Detect a *real* outer transaction only by catching the
  "cannot start a transaction within a transaction" error from `BEGIN` itself; treat
  "database is locked" as `ChainLockUnavailable`.
- Commit via raw `exec('COMMIT')` when we started the transaction; on error, always raw
  `exec('ROLLBACK')` whenever `$weStartedTransaction` (never gate on `inTransaction()`), and
  swallow a secondary `PDOException` so the original error surfaces.

**Invariant to preserve:** marker insertion and envelope append are atomic for
`EloquentChainStore` on SQLite. Any future change must keep "we started it → we
unconditionally COMMIT/ROLLBACK it" and must not reintroduce `inTransaction()` gating.
`tests/Stores/Locking/SqliteChainLockerTest.php` and the rollback test in
`GenericJsonlImporterTest.php` guard this.

## Decisions / caveats to keep

- The marker namespace (`importer()`) is the duplicate boundary: it must include source
  identity + schema version and be ≤ 191 chars. Do not default it to the PHP class name.
- `contentHashFor()` must be a stable lower-case 64-char SHA-256 of the logical record (not a
  line number or byte offset) so reordered files and resumed imports still dedupe.
- The atomic marker + append guarantee holds only for `EloquentChainStore`; do not claim it for
  arbitrary `ChainStore` implementations.
- Claimed keys in bundles remain informational only and are never trusted automatically.
