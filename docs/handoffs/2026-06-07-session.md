1. Confirm the repo is clean and on `main`:

2. Do not redo Chunk 4 or Chunk 5. Chunk 5 is released at `v0.3.0-alpha`.
3. Draft `docs/plans/2026-06-07-chunk-6-jsonl-importer.md` or a newer dated equivalent.
4. Keep the plan at Chunk-4/Chunk-5 quality before implementation:
   - file list and ownership boundaries
   - task ordering
   - acceptance tests
   - commit boundaries
   - explicit done criteria
5. Read Station's reference importer/updater code before finalizing the plan. Use `rg` first; likely search terms:
   - `GenericJsonlImporter`
   - `EloquentImportMarkerTrait`
   - `import marker`
   - `updater`
   - `jsonl`
6. Do not create a new core API unless the adapter plan proves the existing `EvidenceChain`, `ChainStore`, and Eloquent store APIs are insufficient.

Chunk 6 design points to lock before writing tasks:

- Source identity: how an importer names the upstream feed/file and prevents two feeds from sharing a marker accidentally.
- Record identity: what stable key prevents re-importing the same logical record when line offsets or ordering change.
- Marker semantics: last complete checkpoint only; failed records must not advance the checkpoint past unrecorded data.
- Idempotency: rerunning the same import should not emit duplicate attest envelopes.
- Partial failure: decide whether one bad line stops the import, is skipped with diagnostics, or is quarantined.
- Envelope shape: define the default event type and payload fields for imported JSONL records.
- Transactions: define the boundary between marker updates and append operations so a crash cannot claim imported data that was not appended.
- Extensibility: abstract base should let Station provide source-specific parsing/mapping without making this package depend on Station.

## Decisions / caveats to keep

- The package does not auto-register schedules. Operators schedule `attest:anchor` or dispatch `AnchorPendingBatch` explicitly.
- Claimed keys in bundles are informational and are never trusted automatically by bundle verification.
- Guzzle remains optional. Commands that need HTTP use the configured/available PSR-18 stack; the package does not hard-require Guzzle.
- Eloquent read-side index columns are diagnostic/query metadata only. Verification reconstructs envelope state from canonical raw bytes.
- `RefreshDatabase` remains a bad fit for lock-path tests that use SQLite `BEGIN IMMEDIATE`; use `DatabaseMigrations` for those tests.
